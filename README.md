# Sofular Hafriyat & İnşaat - Kurumsal Web Sitesi

Sofular Hafriyat & İnşaat firması için hazırlanmış modern, hızlı, mobil uyumlu ve SEO odaklı kurumsal web sitesi projesi.

🌐 **Canlı Web Sitesi:** [sofularhafriyat.com.tr](https://sofularhafriyat.com.tr)  
📦 **Alternatif GitHub Pages:** [mustafadogans.github.io/sofular-website](https://mustafadogans.github.io/sofular-website/)

---

## 🌟 Proje Özellikleri

- **%100 Duyarlı (Mobile-First Responsive)**: Telefon, tablet, dizüstü ve geniş ekran masaüstü cihazlarla kusursuz uyum.
- **Modern & Şık Tasarım**: İnşaat ve hafriyat sektörüne özel renk paleti, tipografi ve net kullanıcı deneyimi.
- **Hizmet Tanıtımları**: Temel kazısı, bina yıkımı, moloz nakliyesi ve iş makinesi kiralama hizmetlerinin detaylı sunumu.
- **Hızlı İletişim Entegrasyonları**:
  - Tek tıkla WhatsApp üzerinden anında teklif alma
  - Doğrudan arama butonları
  - Kayseri konumlu interaktif harita
- **SEO & Performans Optimizasyonu**: Semantik HTML etiketleri, optimize edilmiş görseller ve meta tag yapılandırması.
- **Özel Alan Adı (Custom Domain)**: CNAME üzerinden Cloudflare / DNS yönlendirmesi ile güvenli SSL bağlantısı.

---

## 🛠️ Kullanılan Teknolojiler

- **HTML5 & CSS3**: Semantik yapı, CSS Grid & Flexbox, özel animasyonlar
- **JavaScript (Vanilla JS)**: Mobil menü kontrolü, dinamik header kaydırma (sticky nav) ve form etkileşimleri
- **İkon Seti**: [Phosphor Icons](https://phosphoricons.com/)
- **Yazı Tipleri**: Inter (Google Fonts)
- **Barındırma**: GitHub Pages (Custom CNAME: `sofularhafriyat.com.tr`)

---

## 📂 Proje Dizin Yapısı

```text
Sofularli/
├── index.html          # Ana sayfa ve tüm bölümler
├── CNAME               # Özel alan adı yönlendirmesi
├── css/
│   └── style.css       # Tasarım ve responsive medya sorguları
├── js/
│   └── main.js         # Etkileşim ve animasyon komutları
└── assets/
    ├── images/         # Logo, banner, galeri ve proje fotoğrafları
    └── icons/          # Yardımcı grafikler
```
